# E01. 나눠 사고판 매매의 손익 계산

> 상태: 평가 기준 확정. 담당자가 페이지 밖에서 검산했다고 했지만 값이 남은 것은 G02의 매매 표 6칸뿐입니다(3절). 규칙 R04, R16의 의견은 받지 않아 초안대로 갑니다.
> 평가 기준을 확정한 날: 2026-11-06

## 1. 문제

투자자는 한 번에 사고팔지 않습니다. 여러 번 나눠 사고팔면 평균 단가와 그때그때의 환율이 얽혀서, 실제로 원화로 얼마를 벌었는지, 그 수익이 가격에서 왔는지 환율에서 왔는지 알기 어렵습니다.

## 2. 가설

"매매 한 건씩 이동평균법으로 계산하는 결정적 코드는 손계산과 원 단위까지 같고, 사람들이 흔히 하는 어림(달러 손익 x 기준일 환율)보다 정확하다."

| 칸 | 내용 |
|---|---|
| 바꾸는 것(X) | 어림 대신 매매 한 건씩 계산하는 코드(Python 계산기, dbt Gold 모델) |
| 재는 것(Y) | 골든 사례 30개의 숫자 일치 |
| 기준선 | 달러 손익 x 기준일 환율(5절에 이미 잰 값) |
| 기대하는 차이(Z) | 기준선은 미국 사례 21개 가운데 1개만 맞음. 코드는 30개 모두 일치 |

모델을 부르지 않는 실험입니다. 뒤의 RAG와 에이전트가 숫자를 믿고 쓸 도구를 만드는 단계이고, 틀리면 그 위에 얹는 모든 것이 틀립니다.

## 3. 평가 기준 (개발 전에 확정)

### 지표와 통과선

| 지표 | 정의 | 통과선 |
|---|---|---|
| 숫자 일치 | 사례 30개의 정답 칸 전부. 규칙 R15대로 반올림한 값 | 전부 정확히 일치 |
| 연 환산 수익률 | `irr_pct`, `bench_irr_pct` | 0.05%p 안 |
| 항등식 | 실현 + 평가 = 합계, 가격 + 환율 + 교차 = 합계. 반올림 전 값으로 | 오차 0.01원 미만 |
| 경고 | 코드와 줄 번호 | 전부 일치 |
| 입력 순서 | 날짜가 다른 매매의 입력 순서를 섞어도 결과가 같음(같은 날 안의 순서는 유지) | 30개 모두 |
| 다시 실행 | 같은 입력을 두 번 넣으면 같은 결과 | 전부 |

### 계산 규칙

평가하려면 "맞다"의 뜻부터 정해야 합니다. 정답은 이 규칙에서 나옵니다.

| 번호 | 규칙 | 이유 |
|---|---|---|
| R01 | 평균 단가는 이동평균법. 매수 때만 바뀌고 매도는 바꾸지 않음. 전량 매도하면 초기화 | 평균 단가를 보여 주는 흔한 방식이고 market-watch도 같음(세금 계산과는 별개) |
| R02 | 원화 원가는 "체결가 x 그 매매의 환율"로 따로 쌓고, 매도 때 같은 비율로 덜어 냄 | 달러 단가에 나중 환율을 곱하면 환율 효과가 사라짐 |

| R04 | 미국 거래일 t의 환율은 같은 날짜 t의 기준율. 없으면 직전 값 | 단순하고 재현됨. 실제 환전 환율은 직접 넣을 수 있음 |
| R05 | 같은 날 안의 순서는 입력 순서. 실제 데이터에서는 `executed_at`, 같으면 `execution_id` 순 | 같은 날 사고팔면 순서에 따라 결과가 다름 |

| R07 | 보유보다 많이 판 줄(`OVERSOLD`), 기준일 뒤 줄(`AFTER_ASOF`), 수량이 0 이하인 줄(`BAD_QTY`)은 그 줄만 빼고 나머지는 계산 | 한 줄 때문에 전체가 멈추지 않게. 공매도는 다루지 않음 |
| R08 | 체결가가 그날 저가와 고가 밖이면 `PRICE_OUT_OF_RANGE` 경고. 값은 그대로 씀 | 시간외 매매 같은 예외가 있을 수 있음 |
| R09 | 남은 수량은 기준일의 종가와 환율로 평가. 없으면 직전 값 | |
| R10 | 효과 나누기. af = 보유 원가(원) ÷ 보유 원가(현지), avg = 평균 단가. 가격 = q x (p - avg) x af, 환율 = q x avg x (fx - af), 교차 = q x (p - avg) x (fx - af). 매도마다, 그리고 남은 수량에 더함 | 세 값의 합이 원화 손익과 정확히 같음 |
| R11 | 단순 수익률 = 합계 원화 손익 ÷ 매수 합계 | |
| R12 | 연 환산 수익률은 원화 현금 흐름(매수 -, 매도 +, 기준일의 남은 평가액 +)의 내부수익률. 날짜 차 ÷ 365. 첫 매매일부터 기준일까지 30일 미만이거나 부호 변화가 없으면 없음. 범위 -99% ~ +100,000% | 나눠 사고팔면 돈이 들어간 때가 달라 단순 수익률이 왜곡됨 |
| R13 | 기준선 비교. 같은 날 같은 원화 금액을 기준 종목(실제로는 SPY)의 그날 종가와 환율로 사고, 매도 때 같은 비율로 팜 | "같은 돈을 넣었다면"의 뜻을 하나로 고정 |
| R14 | 최대 낙폭. 첫 매매일부터 기준일까지 달력의 날마다 누적 손익(실현 + 평가)을 내고, 고점은 0에서 시작해 고점 대비 가장 큰 하락(원) | 매도로 평가금액이 주는 것을 손실로 세지 않음. 첫날 비싸게 산 손실도 셈 |
| R15 | 계산 중에는 반올림하지 않음. 원은 정수, 달러는 소수 둘째 자리, 단가와 환율은 넷째, 수익률은 둘째. 0.5는 0에서 먼 쪽으로 | 표시값끼리 더하면 1원 어긋날 수 있음(G07: -65,700 - 6,300 + 203 = -71,797, 합계 -71,798). 그래서 항등식은 반올림 전 값으로 검사 |
| R16 | 범위 밖: 수수료, 세금, 배당과 분배금, 환전 수수료, 소수점 매매, 공매도 | 먼저 핵심을 맞춤. 수수료는 다음 후보 |
